# ButovskyESIM — Telegram-бот продажи eSIM

Однофайловый Telegram-бот на Python 3.10+ без сторонних Python-пакетов. Профили,
заказы, настройки доступности стран и незавершённые этапы сохраняются локально
в JSON-файлах. Профили пользователей хранятся по адресу `data/users/<TelegramID>.js`.

## Возможности

- Регистрация по Telegram ID, имени, фамилии и номеру телефона.
- Заказ по направлениям и странам из заданного каталога.
- Закрытие для покупки целого направления или отдельной страны.
- Профиль пользователя, баланс и список активных заказов.
- Базовая проверка поддержки eSIM по модели устройства. Региональные версии
  устройств необходимо дополнительно проверять у производителя.
- Админ-панель: список и блокировка пользователей, просмотр их заказов,
  управление статусами и доступностью направлений/стран.
- Обработка заказа по этапам: период, пакет трафика, цена и текст оплаты,
  подтверждение чека, отправка инструкции пользователю.
- Инструкции пересылаются сообщениями Telegram, в том числе документами,
  фотографиями, видео и аудио.
- Заявки и незавершённые этапы сохраняются на диске и переживают перезапуск.

## Установка на Linux-сервер с systemd

Требуются Python 3.10+, `systemd`, `sudo` (если команда запускается не от root)
и доступ сервера к Telegram Bot API.

1. Склонируйте репозиторий на сервер и перейдите в папку проекта.
2. Запустите:

   ```bash
   bash start.sh
   ```

3. Введите токен бота (ввод скрыт) и Telegram ID администратора.
4. Откройте диалог с ботом и отправьте `/start`. Администратор тоже должен
   сначала открыть бота и отправить `/start`, иначе Telegram не разрешит боту
   отправлять ему уведомления.

Скрипт установит службу `esim-telegram-bot`, включит её автозапуск при загрузке
сервера и сохранит параметры в `/etc/esim-telegram-bot.env` с правами `0600`.
Исходник и данные службы хранятся в `/opt/esim-telegram-bot`.

```bash
systemctl status esim-telegram-bot
journalctl -u esim-telegram-bot -f
```

Чтобы применить изменения в `bot.py`, повторно запустите `bash start.sh`.
Скрипт снова запросит токен и ID администратора, обновит копию исходника
и перезапустит службу. Данные пользователей и заказов при обновлении не удаляются.

## Работа с оплатой и выполнением заказа

Встроенного эквайринга и подключения к оператору eSIM здесь нет: администратор
вручную указывает цену в рублях и текст/реквизиты оплаты. Пользователь присылает
чек в боте, а администратор подтверждает или отклоняет его. После подтверждения
администратор прикрепляет инструкцию, и бот отправляет её пользователю.
Не отправляйте в бота реквизиты карт или другие секретные платёжные данные.

Проверка совместимости — ориентировочная: наличие eSIM может зависеть от
региональной версии устройства, оператора и блокировки SIM. Поддержку нужно
подтверждать для полного кода модели перед продажей.
